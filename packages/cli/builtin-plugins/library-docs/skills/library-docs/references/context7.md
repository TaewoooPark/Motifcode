# Context7 in Motif

The server's current schema is authoritative. Its documented tools are `resolve-library-id` (library name and task query) and `query-docs` (returned library ID and question). Motif does not expose these as top-level functions: dispatch through `mcp` with the discovered server and method.

A useful query: “For the installed React major version, how do I cancel a fetch when the selected item changes?” A poor query: “Everything about React.” Split a second query only when the first result leaves a concrete API uncertainty.

Context7 may index community documentation. Prefer the official project's ID, verify incompatible examples against installed declarations, and cite the returned source page. No search result is a guarantee that the requested release is covered.

Official reference: https://github.com/upstash/context7

This bundle contains original Motif workflows; it does not install or reproduce the upstream Context7 plugin.
